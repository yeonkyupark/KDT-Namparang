# 데이터 출처 및 이용 조건

이 프로젝트는 **개인의 비상업적 트레킹 기록 용도**로 만들어졌다.
아래 자료는 모두 제3자가 만든 것이며, 이 리포의 저작물이 아니다.

---

## 1. 남파랑길 GPX 노선 (`data/gpx/`)

| 항목 | 내용 |
|---|---|
| **원저작자** | Daum 카페 **"도보여행(섬&산) 좋은사람들"** 회원 (gps 게시판 게시글 작성자) |
| **출처 URL** | https://cafe.daum.net/mtsingles/LN1X/1631 |
| **게시글 제목** | 남파랑길 전코스 |
| **수집일** | 2026-08-27 |
| **파일 수** | 92개 (본 코스 90 + `17-1` 거제 임시우회 + `61-1` 순천만 흑두루미 보호기간 우회) |
| **총 용량** | 14.4 MB |
| **명시된 라이선스** | **없음** |

### 원저작자에 대해

이 GPX는 자동 생성물이 아니다. 게시글 작성자가 **남파랑길 90개 코스를 직접 걸으며** 노선을 확인하고
정리해 카페에 공유한 자료다. 코스 접합부 89곳이 모두 500m 이내로 이어지는 품질은 이 수작업의 결과다.

원저작자의 노력에 대한 감사를 여기 기록해 둔다.

### 파일별 원 제작 도구

92개가 단일 출처는 아니다. `creator` 속성 기준:

| 도구 | 파일 수 |
|---|---|
| GPS Track Editor | 75 |
| GPS Visualizer | 16 |
| **Korea Tourism Organization** | **1** (`nam-03.gpx`) |

`nam-03.gpx`는 한국관광공사가 만든 원본이 그대로 포함된 것으로 보인다.
`<trk><name>`이 `"GPX"`뿐이어서 지점명 정보가 없고, 세그먼트 태그가
표준 `<trkseg>`가 아니라 **`<trkseq>`로 오타**가 나 있다 (92개 중 유일).
**원본을 수정하지 않고** `scripts/lib/gpx.mjs`의 파서가 컨테이너 태그 이름을
무시하도록 만들어 대응했다.

### 왜 이 자료가 여전히 필요한가 (2026-08-27 재검토)

공식 자료로 대체할 수 있는지 검토했고, **노선 좌표는 대체할 수 없다**는 결론이다.

- 두루누비 공식 GPX 는 받을 수 없다 (3번의 "공식 GPX 는 받을 수 없다" 참조)
- 공식 목록 API 는 시작·종료 좌표 4개 값만 준다 — 경로 폴리라인이 없다
- 이 앱은 92개 코스 3,886점(오버뷰) + 744KB(상세 + 고도)의 좌표를 필요로 한다

**이 GPX 는 전체 경로 좌표를 가진 유일한 자료다.** 대신 좌표 외의 정보
(지점명·주소·교통편·지역·난이도·소요시간)는 전부 공식 자료로 교체했다.

노선을 공식 것으로 바꾸려면 사용자가 두루누비에서 직접 GPX 를 내려받아
`data/gpx/` 에 넣으면 된다. 파이프라인은 그대로 동작한다.

### 이용 방침

- **출처와 원저작자를 반드시 표기한다** (README, 앱 화면 하단, 이 문서)
- **재배포·상업적 이용을 하지 않는다.** 이 리포는 개인 기록 용도다
- **원저작자 또는 카페 운영진이 요청하면 즉시 `data/gpx/`를 삭제하고 원문 링크만 남긴다**
- 노선을 수정하지 않는다. 계산된 파생 데이터(거리·고도·소요시간)만 별도로 생성한다

> **재배포 부담이 있다고 판단되면** `data/gpx/`를 리포에서 제외하고(`.gitignore`),
> `scripts/fetch-gpx.mjs`로 각자 내려받게 하는 방식으로 전환할 수 있다.
> 그 경우에도 `data/raw/downloaded.json`의 SHA1 목록으로 동일성을 검증할 수 있다.

### 재현 정보

| 파일 | 내용 |
|---|---|
| `data/raw/attachments.json` | 원본 첨부 92개의 파일명 + CDN URL |
| `data/raw/downloaded.json` | 정규화 파일명 · 바이트 수 · **SHA1** |
| `data/raw/validate.json` | 전수 검증 결과 (코스별 점 개수, 거리, 시작/종료 좌표, `trk name`) |

파일명은 `nam-01.gpx` ~ `nam-90.gpx`, `nam-17-1.gpx`, `nam-61-1.gpx`로 정규화했다.
**파일 내용은 원본 그대로이며 한 바이트도 변경하지 않았다.**

| **내용** | 90개 코스 × (거리 km, 누적상승 m, 지역) |
| **합계** | 1,429.9 km / 누적상승 38,070 m |

### 수집 방법과 준수 사항

- `robots.txt`가 `Allow: /`로 허용한 **공개 HTML 페이지에서 렌더된 수치만** 읽었다
- 해당 사이트의 `robots.txt`는 `/api/`를 전면 차단하고 `ClaudeBot`·`Claude-User`·`anthropic-ai`를
  명시적으로 지정해 두었다. **이를 확인한 뒤 API 접근을 중단했다**
- **GPX 노선 데이터는 받지 않았고 사용하지도 않는다.** 이 프로젝트의 노선은 100% 위 1번 자료다
- 숫자 90쌍을 참고 지표로만 쓰며, 이 자료를 우리 산출물로 재배포하지 않는다

## 3. 코스 메타데이터 (`data/courses.meta.csv`, `data/reference/durunubi-courses.json`)

| 항목 | 내용 |
|---|---|
| **출처** | 두루누비 (한국관광공사) — https://www.durunubi.kr/namparang-course-list.do |
| **수집 경로** | 사이트가 목록을 채우는 데 쓰는 `/api/course/list?type=DNWW&serviceFlag=NA` |
| **수집일** | 2026-08-27 |
| **내용** | 90개 코스 × (시점·종점 지점명·주소·교통편, 시군, 공식 거리·소요시간·난이도, 코스 설명) |
| **라이선스** | **공공누리 제4유형** — 출처표시 + 상업적이용금지 + **변경금지** |

> 상세 페이지에 명시된 문구: *"한국관광공사에서 제작한 본 공공저작물은 공공누리
> '출처표시+상업적이용금지+변경금지' 조건에 따라 이용할 수 있습니다."*
>
> **변경금지 조건이 있다.** 이 프로젝트는 공식 텍스트(`travelerInfo`)를 파싱해
> 필드로 재구성하고 `public/data/courses.json` 에 담아 공개 리포에 올린다.
> 이것이 "변경"에 해당하는지는 해석의 문제이고, 나는 법률 판단을 할 위치가 아니다.
> 사실만 적어둔다: **출처는 표기했고, 상업적 이용은 하지 않으며, 원본 응답을
> `data/reference/durunubi-courses.json` 에 그대로 보관했다.** 한국관광공사가
> 요청하면 즉시 삭제한다 (문의처: 각 코스의 `koglContact`).

### robots.txt 준수

- `robots.txt` 의 `User-agent: *` 가 차단한 경로는 `/api/campaign/...`, `/api/dmzadmin`,
  `/api/dmz`, `/api/poi/main`, `/api/tracking`, `/dmzadmin`, `/download`, `/KTO/`,
  `travelRoad.do`, `travelRoadV2.do`, `saveBeforeLogin.do` 다.
  **우리가 쓴 `/api/course/list` 와 목록 페이지는 차단 대상이 아니다.**
- **`/download` 가 차단되어 있어 두루누비의 GPX 는 받지 않았다.** 노선 데이터는
  1번(Daum 카페) 자료를 그대로 쓴다.
- 요청은 총 3회(목록 페이지 1 + API 2)만 보냈다.

### 공식 GPX 는 받을 수 없다 (2026-08-27 확인)

두루누비의 노선 GPX 를 받으려 했으나 두 경로 모두 막혀 있다.

| 경로 | 결과 |
|---|---|
| `gpx_src` (`/data/koreamobility/course/summap/*.gpx`) | **HTTP 404** — 직접 접근 불가 |
| 상세 페이지의 실제 다운로드 (`/download?filePath=...`) | **`robots.txt` 가 `/download` 를 차단** |

목록 API 도 좌표는 **시작·종료 4개 값만** 준다. 경로 폴리라인이 없다.
따라서 **공식 자료만으로는 지도에 선을 하나도 그릴 수 없다.**

### 이용 방침

- 공공기관(한국관광공사)이 공개한 관광 정보다. 출처를 표기하고 개인 비상업 용도로만 쓴다.
- 원본 응답을 `data/reference/durunubi-courses.json` 에 그대로 보관해 재현 가능하게 했다.
- 우리 노선(1번 자료)과 **공식 코스 경계가 다른 14개 슬롯**에는 공식 지점명을 쓰지 않았다.
  자세한 내용은 `PLAN.md` 0.4 참조.

## 5. 고도 데이터 (`data/cache/ele/`)

| 항목 | 내용 |
|---|---|
| **출처** | SRTM 30m DEM (NASA/USGS), opentopodata.org 공개 API 경유 |
| **정확도** | 수직 오차 **±16m 수준** |
| **표기** | 앱 화면에 "고도는 DEM 추정값" 각주를 표시한다 |

원본 GPX의 `<ele>`는 92개 중 82개가 전부 `0.00`이고, 값이 있는 10개도 대부분 무의미하다
(`nam-88`은 325 상수, `nam-73/83/84`는 0~18m). 실측 고도는 `nam-23` ~ `nam-27` 5개뿐이다.
따라서 **모든 고도 지표는 우리가 DEM으로 산출한 추정값**이며, 위 5개 코스와
2번 참고자료로 이중 검증한다.

GPX의 `<time>`은 2020-01-16~20 사이 15분 간격으로, 편집 시각이지 보행 시간이 아니다.
**사용하지 않는다.** 소요시간은 네이스미스 규칙으로 계산한 값이다.
